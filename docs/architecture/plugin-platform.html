The one-paragraph version

shuv2code is already ~85% hexagonal: a pure orchestration core, ports as Effect services, adapters at the edges. This bundle finishes that architecture and then makes the seams loadable. Features become plugins with manifests; the orchestration core stops gaining feature-specific branches; providers, VCS, voice, and surfaces all load through the same path an external author would use. Full trust by default — restrictions are configured, never begged for.

The signature change that matters most

Adding a feature used to mean editing the pure core. It never means that again:

- // decider.ts — case "thread.voice.exchange.append": { ... }
+ // decider.ts — one generic delegation:
+ dispatchExtensionCommand(envelope, state) → owningPlugin.decide(command, state) → events

The trust model

LayerWho decidesMechanism
Run this plugin at all?You, in configopencode-v2-style layered entries: global enablement, per-project declarations, location-relative resolution, project wins on conflict
What can it touch?You, optionallyManifest capabilities are restrictions you may impose, not permissions you grant. Default: full trust.
Is it enforced?The software, honestlyIn-process = trusted code, like npm lifecycle scripts. Three brokered chokepoints (secrets, exec, fs-outside-workspace) enforce declared restrictions. No sandboxing theater.

North star (shapes now, machinery never-yet)

Ports are instance-agnostic and placement-flexible: a plugin may someday run on your local instance acting on a cloud instance, or exist meaningfully only on mobile. Nothing cross-instance ships in this bundle — but no port shape will need to break when that day comes.

What is deliberately not built

No daemons. No bridge protocols. No marketplaces. No content addressing. No grammar versioning. No conformance kits. Every one of those exists elsewhere to protect strangers running untrusted code at distance. Our users are developers who chose the code. The moment that changes, the port shapes are ready — until then we build features.
